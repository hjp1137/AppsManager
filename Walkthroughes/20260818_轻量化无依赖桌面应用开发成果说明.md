# 轻量化无依赖桌面应用重构开发成果说明

## 一、 交付背景与解决痛点
针对原 .NET 9 WPF 方案在分发时对运行时强依赖（自包含打包需 80~120MB+）、海量日志刷屏卡死主 UI 线程、以及多开应用时单服务卡死拖垮全局的核心缺陷，已完成基于 **Go 核心引擎 + 硬件加速终端 (xterm.js) + 现代暗黑 Web UI** 的轻量化重构与交付。

---

## 二、 核心成果与指标

1. **零外部环境安装依赖 & 极致轻量 & 无控制台黑框**：
   * 采用 Go 原生静态编译，加入 `-H windowsgui` 参数，彻底去除启动时的控制台黑框窗口，静默后台运行。
   * 单文件可执行程序 `AppsManager.exe` 体积仅 **7.10 MB**（体积降低 90% 以上）。
   * 目标电脑无需安装 .NET Runtime、Python、Node 等任何软件，双击单 EXE 即可秒开。
   * 闲置运行内存降至 **15MB ~ 25MB**。
   * 界面右上角增设【🛑 退出程序】按钮，点击即可优雅关停所有子服务并彻底释放退出。


2. **解决海量 Log 刷屏卡死 & 终端抽屉上下拖动拉伸高度调节 & 项目名日志标题**：
   * **后端定长环形缓冲 (Ring Buffer)**：每个子服务限制最大保留 3000 行日志，彻底防止内存无上限暴涨。
   * **50ms 微批处理节流 (Batch Throttle)**：将增量日志在 50ms 时间窗口内打包推送，消除 IPC 消息风暴。
   * **xterm.js Canvas 硬件加速**：完全绕过浏览器 DOM 树重排，即使每秒输出上万行日志依然保持 60 FPS 丝滑响应。
   * **上下拖动拉伸高度调节 (Resize Splitter)**：终端抽屉顶部边框支持鼠标上下拖拽自由调节高度（100px ~ 800px+），持久化记录用户偏好高度，并内置 `ResizeObserver` 自动重测自适应终端画布。
   * **日志标题展示项目名称**：下方控制台 Tab 及终端标题清晰展示为 `项目名称 · 子服务名称`，多项目时一目了然。

3. **彻底隔离多进程防假死 & 纯系统命令原生调试 & 原子并发防重 & 专属高清图标**：
   * **Actor 协程完全物理隔离**：每个子服务运行在专属的独立 Goroutine + Context 中，单个命令假死或死循环完全不影响其他服务和主界面。
   * **日志单行单网址严格起始对齐 & 原生青色高亮 & 像素级下划线定位**：
     - 将多网址拆分为严格的单行单网址展示（`本地 IP 访问:`、`本地域名访问:`、`局域网访问:`），中文与字符等宽严格对齐至同一列；
     - 网址颜色严格恢复为清晰悦目的青色高亮（`\x1b[36m`）；
     - 彻底解决 xterm 下划线向左偏移缺陷：重构 `registerLinkProvider` 坐标算法，通过 `line.getCell(col)` 动态累计全角双宽度字符（CJK 汉字），将 JS 字符下标精准转换为 1-based 物理网格 Cell 列坐标，鼠标悬停时下划线 100% 精确贴合在 URL 正下方。
   * **日志标题行展示所有可用链接标签**：
     - 顶部工具栏同时呈现当前服务的所有有效入口（`127.0.0.1`、`localhost` 及局域网 IP），每个链接标签独立支持点击在新窗口打开。
   * **侧边栏分组数量绝对像素对齐 & 卡片拖拽移入分组 & 自定义分组高亮拖拽排序**：
     - **数量绝对垂直对齐**：重构分组 Item 布局结构，将编辑/删除操作按钮收拢为 hover 显现，右侧 `(N)` 数量徽章统一采用固定基准排版，所有分组数量无论在 hover 与否均 100% 垂直精确对齐；
     - **高亮 SVG 点阵把手**：自定义分组把手升级为独立的 6 散点 SVG 矢量点阵图标，颜色调整为明亮的银灰蓝（`#94a3b8` / `#60a5fa`），彻底消除暗黑背景下的融入感；
     - **卡片拖拽移入分组**：卡片支持原生 HTML5 拖拽（`draggable`），当拖拽卡片至侧边栏任一目标分组（如“默认”、“测试”等）时触发亮蓝色高亮反馈，松手即自动修改该项目所属分组并持久化同步；
     - **自定义分组拖拽排序**：“全部项目”与“默认”固定在最上方，自定义分组（如“测试”、“自用码”等）支持抓取把手自由拖拽上下排序，拖拽调整后即时持久化至 LocalStorage。
   * **程序版本号规范化升级为 v1.0**：
     - 顶部导航栏 Logo 旁版本号徽章规范升级为 `v1.0`。



   * **AppsManager.exe 嵌入专属高清应用图标**：
     - 生成了包含 256x256, 128x128, 64x64, 48x48, 32x32, 16x16 全套尺寸的科技发光闪电专属 `.ico` 图标；
     - 借助 Windows PE 资源对象 `app.syso` 嵌入编译，在 Windows 资源管理器、任务栏、桌面均呈现精美现代图标。
   * **停止服务实时日志回显**：点击【⏹ 停止】或进程退出，日志界面立即输出醒目的红色停止回显与端口释放通知。

   * **用户自定义端口最高优先级保护**：只要用户显式配置了端口（如 5001），系统绝对锁定用户设置，绝不再被日志中的历史端口覆盖篡改！
   * **终端日志 URL 原生点击直接跳转浏览器**：为 xterm.js 终端集成原生 `registerLinkProvider` URL 正则解析器，点击即可直接在浏览器新标签页中打开访问！
   * **经典 SVG 复制图标 & 紧贴路径排版 & 非阻塞 Toast 提示**：项目名称与物理路径后统一采用经典高清晰度双层矩形 SVG 复制图标，路径复制按钮紧贴在路径文字后面。











4. **100% 兼容历史数据 & 系统原生文件夹选择器 & 穷举式深度智能识别引擎**：
   * 完美兼容现有 `%LOCALAPPDATA%\AppsManager\projects.json` 配置。
   * 新增 Windows 原生文件夹选择对话框支持（`/api/system/select_folder`），弹窗中点击【📁 选择文件夹】可直接浏览本地目录，选择后自动回填路径、提取项目名并自动触发智能识别。
   * **模块化穷举式识别引擎 (`core/rules_config.go` + `core/rules.go` + `core/detector.go`)**：
     - **多层级递归扫描**：自动递归扫描根目录及深度 <= 3 级的所有有效子目录（智能跳过 node_modules、.git、bin、obj、dist 等）。
     - **全生态预置**：预置覆盖 Node 前端、.NET Web/Worker/Exe、Python (Django/FastAPI/Flask/Streamlit)、Go、Java Spring Boot、Rust 等。

5. **识别规则可视化管理页面 (增删改查、启用/禁用、恢复默认、居中大弹窗)**：
   * **顶栏视图切换**：顶部导航栏支持在【🖥️ 服务监控】与【⚙️ 识别规则管理】之间无缝一键切换。
   * **居中大弹窗体验**：新建与编辑规则采用 680px 居中大弹窗与毛玻璃半透明遮罩设计，表单项规范排版，暗黑精致。
   * **可视化 CRUD**：
     - **实时检索与分类筛选**：支持按规则名、特征文件、启动命令及技术生态（全部、Node/前端、.NET、Python、Go、Java、Rust）毫秒级过滤。
     - **新增与编辑**：支持自定义规则名称、技术分类、特征文件、内容匹配关键字、启动命令模板、默认端口。
     - **一键开关与删除**：行内直接启用/禁用特定规则，即时生效；支持单项删除与一键恢复出厂默认预置规则。
   * **持久化与 API**：配置读写于 `%LOCALAPPDATA%\AppsManager\detection_rules.json`，提供 `/api/rules` 与 `/api/rules/reset` 完整 REST API。
