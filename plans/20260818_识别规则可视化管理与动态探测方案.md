# 识别规则可视化管理与动态探测方案

## 一、 需求背景
为使项目类型识别具备完全的开放性与自定义能力，需增加独立的“项目识别规则管理”页面，支持对各类编程语言与框架的特征文件、匹配内容、启动命令模板及默认端口进行增、删、改、查、启用/禁用和恢复默认预置配置。

## 二、 架构设计

### 1. 数据模型与持久化 (`core/model.go` & `core/rules_config.go`)
* 规则结构体 `DetectionRule`：
  - `Id`: string (唯一标识)
  - `Name`: string (规则名称)
  - `Category`: string (技术生态)
  - `MatchFile`: string (特征文件通配符/名称)
  - `MatchContent`: string (文件内容特征关键字)
  - `Command`: string (启动命令模板)
  - `DefaultPort`: int (默认端口)
  - `PortExtractRegex`: string (端口正则)
  - `Enabled`: bool (是否启用)
  - `IsBuiltin`: bool (是否预置)
* 持久化于 `%LOCALAPPDATA%\AppsManager\detection_rules.json`，缺失时自动生成全套内置规则。

### 2. 后端服务与动态探测 (`core/server.go` & `core/detector.go`)
* 路由接口：
  - `GET /api/rules`：获取所有识别规则。
  - `POST /api/rules`：新增/保存/更新规则。
  - `POST /api/rules/reset`：重置恢复出厂预置规则。
* `Detector` 调度器读取活跃规则列表，遍历目录执行动态模式匹配与端口嗅探。

### 3. 前端交互与视图 (`frontend/src/views/RulesView.vue` & `frontend/src/App.vue`)
* 顶部导航栏无缝切换【🖥️ 项目监控】与【⚙️ 规则管理】视图。
* 规则管理视图包含搜索栏、分类筛选器、新增弹窗、编辑、删除、一键开关与恢复预置。

## 三、 自验证计划
1. `go test -v ./core`：验证规则增删改查、动态探测与序列化。
2. `scratch/test_rules_api.ps1`：端到端验证 `/api/rules` 的增删改查与重置接口。
3. `pnpm build` 与 `go build` 构建验证。
